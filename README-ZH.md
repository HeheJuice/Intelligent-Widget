# 智能小工具

[![GitHub Downloads](https://img.shields.io/github/downloads/HeheJuice/Intelligent-Widget/total?color=blue&label=總下載&style=for-the-badge)](https://github.com/HeheJuice/Intelligent-Widget/releases)

> 適用於 `One UI 7 或更新版本`

> 一個隨你所需而變化的小工具

</div>


## 功能

> 🎶 顯示正在播放的媒體

> 🖼️ 圖片小工具 —— 可自訂圖片、文字、日期及字型

> 🪫 低電量提醒

> ⚡ 充電指示（待機模式，4×2）

> 🔵 藍牙音樂建議

> 📅 依時間變化的待機操作（日曆、新聞、鬧鐘、模式、天氣）

> 🎨 Material 3 動態色彩（Monet）

> 🌈 依時間變化的待機漸層背景

> ⚙️ 小工具模式 —— 自動 / 待機 / 音樂 / 圖片

## 小工具尺寸

> 2×1、3×1、4×1（另有精簡版）

> 2×2、4×2
