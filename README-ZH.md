# 智能小工具

> 適用於 `One UI 7 或更新版本`

> 一個隨你所需而變化的小工具

## 兼容性

> `One UI 7 或更新版本`

> 必須使用 `One UI Home`

> 「模糊背景」需要 `旗艦級 Galaxy 裝置`

## 功能

> 🎶 顯示正在播放的媒體

> 🖼️ 圖片小工具 —— 可自訂圖片、文字、日期及字型

> 🪫 低電量提醒

> ⚡ 充電指示（待機模式，4×2）

> 🔵 藍牙音樂建議

> 📅 依時間變化的待機操作（日曆、新聞、鬧鐘、模式、天氣）

> 🎨 Material 3 動態色彩（Monet）

> 🌈 依時間變化的待機漸層背景

> ⚙️ 小工具模式 —— 自動 / 待機 / 音樂 / 圖片

## 小工具尺寸

> 2×1、3×1、4×1（另有精簡版）

> 2×2、4×2

## 下載

請前往 [Releases 頁面](https://github.com/HeheJuice/Intelligent-Widget/releases) 下載最新 APK。

本應用程式僅以編譯後的 APK 形式發佈，並不提供原始碼。
