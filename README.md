# Intelligent Widget

> For `One UI 7 and newer`

> A `Widget` that adapts to your needs

## Compatibility

> `One UI 7 or newer`

> `One UI Home` is `required`

> `Blur Widget Background` requires a `flagship Galaxy device`

## Features

> 🎶 Currently playing media

> 🖼️ Image Widget — custom image, text, date, and font

> 🪫 Low battery reminder

> ⚡ Charging indicator (Idle mode, 4×2)

> 🔵 Bluetooth music suggestion

> 📅 Time-based Idle actions (Calendar, News, Alarms, Modes, Weather)

> 🎨 Material 3 dynamic color (Monet)

> 🌈 Time-based idle gradient background

> ⚙️ Widget modes — Auto / Idle / Music / Image

## Widget sizes

> 2×1, 3×1, 4×1 (with compact variants)

> 2×2, 4×2

## Downloads
